# Generate OpenSpec assets at build time from the installed package

Pi OpenSpec renders its skills and `/opsx-*` prompts during `pnpm run build` by importing the rendering modules of the pinned `@fission-ai/openspec` devDependency, instead of checking in copies of `openspec init`'s output. This keeps the shipped assets in lockstep with the pinned OpenSpec release — the rendering version is recorded in each skill's `generatedBy` frontmatter — and keeps the repository free of duplicated, hand-maintained skill and prompt text. The trade-off is that the build depends on OpenSpec's internal `dist/` module layout, which is not a stable public API; the Bump OpenSpec workflow therefore runs the package's full check, build, and smoke suite against every candidate version before opening a pull request, so a layout change fails the bump rather than the release.
